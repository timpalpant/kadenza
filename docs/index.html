Kanzi

A native Apple Music experience for KDE Plasma, built with Qt, Kirigami, and MusicKit.

Download Source code

Music that belongs on Plasma

  • Native libraryFast Qt models for songs, albums, artists, playlists, history, and search.
  • Complete playerNow Playing, lyrics, an editable queue, favorites, playlists, and restored playback state.
  • Plasma integrationMPRIS, media shortcuts, notifications, desktop actions, and an optional system tray.
  • Adaptive interfaceKirigami navigation becomes a focused single-pane layout in compact windows.
  • Honest DRM boundaryOnly licensed audio decoding runs in a hidden Widevine-enabled sidecar.

Kanzi in action

Build from source

npm --prefix sidecar install
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/kanzi

Full playback requires an active Apple Music subscription, a network connection, and x86-64 Linux. Offline playback is unavailable because Widevine does not provide persistent licenses on Linux.

Kanzi is unofficial and is not affiliated with or endorsed by Apple.
